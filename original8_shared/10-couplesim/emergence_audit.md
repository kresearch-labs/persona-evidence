# EMERGENCE AUDIT — Week 1 (Days 1–7, Thursday–Wednesday)

**Corpus:** couple_bible.md (seed canon), 7 input pairs (`boy/boy_in.md`, `girl/girl_in.md`), 7 answer files (`boy/answer.md`, `girl/answer.md`), weaves day1–day7.md.

**Criteria.**
- **EMERGED** — a behavior, ritual, or formulation present in a person's answers that is *not prescribed* by the bible or that day's input: the person's own move. First-appearance = earliest answer file in the week.
- **PLANTED** — a setup element traceable to the bible or an input, with plant moment and harvest moment recorded.
- **Honesty limits, stated up front:** (1) *Feedback loop* — the director's later inputs deliberately re-feed emerged behavior as REMINDER material (e.g., day-7 `boy_in.md` quotes the day-5 Tom sentence back). That stabilizes a behavior but does not create it; only first appearances count as emergence here. (2) Pat and Beata appear only as texts — their interiority is never on the page; "reform" is inference from three data points, not observation. (3) The medical content of Beata's three options is NOT IN CONTEXT anywhere in the corpus. (4) Single run, two agents, no control couple — this audit measures the corpus, not a population.
