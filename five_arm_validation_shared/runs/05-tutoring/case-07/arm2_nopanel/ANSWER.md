# Case 07 — Answer

## 1. The misconception

The student has mixed up **factors** with **multiples** — in other words, confused **GCF** (Greatest Common *Factor*) with **LCM** (Least Common *Multiple*).

Their reasoning — "the biggest number both 24 and 36 go into" — actually describes a common **multiple** (a number that 24 and 36 both divide into evenly). Two extra slips follow from that:

- They then grabbed the *greatest* such number (72), but common multiples go on forever (72, 144, 216, …), so there is no "greatest" one — the useful one is the **least** common multiple, which is what 72 happens to be.
- The problem doesn't ask for a multiple at all. The number of kits must divide evenly into both 24 and 36, so it must be a common **factor** — and *that* is where "greatest" makes sense.

## 2. Explaining the correct concept to the student

**Factors go in; multiples come out.**

- A **factor** of a number is a smaller (or equal) number that goes **into** it evenly. Factors of 24: 1, 2, 3, 4, 6, 8, 12, 24. Factors of 36: 1, 2, 3, 4, 6, 9, 12, 18, 36.
- A **multiple** of a number is a bigger (or equal) number you get by multiplying it: 24, 48, 72, 96, … Multiples never end, so there's no biggest one — that's why "the greatest number both go into" can't be the GCF.

**GCF = the biggest number on *both* factor lists.** For 24 and 36, the shared factors are 1, 2, 3, 4, 6, 12 — and the greatest is **12**.

**Why 12 fits this problem:** Mrs. Lee is splitting the pencils and erasers into equal kits with nothing left over. So the number of kits must go **into** 24 evenly *and* into 36 evenly — it's a common factor. The greatest number of kits is therefore **12**, with 24 ÷ 12 = 2 pencils and 36 ÷ 12 = 3 erasers in each kit.

**Quick check for a similar problem:** ask "is the answer a number that goes *into* both amounts (factor) or a number both amounts go *into* (multiple)?" Splitting things into equal groups → factor (GCF). Repeating events that line up (bells ringing, laps meeting) → multiple (LCM).
