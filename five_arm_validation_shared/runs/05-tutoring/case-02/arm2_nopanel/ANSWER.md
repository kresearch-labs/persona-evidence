# Case 02 — Answer

## 1. The misconception behind the answer

The student believes that whatever operation you *see* in the equation is the operation you *do* — "I saw the +3, so I added 3." They have memorized the rule "do the same thing to both sides" but misapplied it: instead of using the **inverse (opposite) operation** to undo what is being done to x, they repeated the operation that was already there. So they turned 2x + 3 = 11 into 2x = 14 by adding 3 to the right side, when the +3 needed to be *removed* by subtracting 3 from both sides. Underneath this sits a second, related gap: they don't yet see the equation as a balance where x is a hidden quantity being built up (×2, then +3), so they don't know the goal is to *peel operations off x in reverse order*.

## 2. Explaining the correct concept to the student

Think of an equation like a balance scale: whatever is on the left must equal whatever is on the right, and the equals sign stays true only if you do the exact same thing to **both** sides.

The letter x is a mystery number that someone processed in steps: they multiplied it by 2, and then added 3. Your job is to work backwards and undo those steps, one at a time, using **opposite operations**:

- The opposite of **+ 3** is **− 3**
- The opposite of **× 2** is **÷ 2**

Undo in **reverse order** (last thing done comes off first):

1. Subtract 3 from both sides:  2x + 3 − 3 = 11 − 3  →  2x = 8
2. Divide both sides by 2:  2x ÷ 2 = 8 ÷ 2  →  **x = 4**

Then always check by putting your answer back in: 2(4) + 3 = 8 + 3 = 11 ✓ — the balance holds.

A quick way to remember it: **the sign in front of a number tells you what was done; you undo it with the opposite.** Saw "+3"? Subtract 3. Saw "−5"? Add 5. Saw "×2"? Divide by 2.

Try this one yourself: 3x + 5 = 20. (Undo +5 first: 3x = 15; then undo ×3: x = 5. Check: 3(5) + 5 = 20 ✓)
