# Case 04 — Answer

## 1. The misconception
The student believes that a percent increase and an equal percent decrease cancel each other out ("+20% and −20% = 0% net change"). The underlying error is treating percentages as fixed absolute amounts instead of relative changes applied to *different bases*. The 20% increase is taken on the original $80, but the 20% discount is taken on the new, higher price — so the two "20%"s are not the same number of dollars and cannot cancel.

## 2. Explaining the correct concept to the student
Percent means "per hundred of *something*" — always ask: 20% **of what**?

- Step 1: The price goes up 20% **of $80**. That's 0.20 × $80 = $16, so the new price is $80 + $16 = **$96** (equivalently, $80 × 1.20).
- Step 2: The sale takes 20% off **the new price, $96** — not off $80. That's 0.20 × $96 = $19.20 off, so the sale price is $96 − $19.20 = **$76.80** (equivalently, $96 × 0.80).

Notice the increase added $16 but the decrease removed $19.20. Same percent, different base, different dollars. Because the discount was computed on a bigger number, it took away more than the increase added — that's why you don't end up back at $80.

Quick check you can always use: multiplying by 1.20 then by 0.80 is the same as multiplying by 1.20 × 0.80 = 0.96, i.e. a 4% overall decrease, not 0%. So $80 × 0.96 = $76.80.

Try it yourself: a $50 game is marked up 10%, then discounted 10%. (Markup: $50 × 1.10 = $55; discount: $55 × 0.90 = $49.50 — again slightly less than where you started.)

**Justification:** The correct price is $76.80 because each 20% is applied to a different base ($80 for the increase, $96 for the decrease), so the changes do not cancel.
