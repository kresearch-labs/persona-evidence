# Case 22 — Answer

**Correct sentence:** "You're going to love your new phone."

## 1. The misconception

The student believes that an apostrophe always signals possession ("Maria's book" → so "you're" must be the possessive form that goes before a noun). In reality, apostrophes have two different jobs: showing possession AND marking a contraction (letters left out). In "you're," the apostrophe shows a missing letter — it stands for "you are" — while "your" (no apostrophe) is the possessive word. The student overgeneralized one rule ("apostrophe = ownership") to a word where the apostrophe actually means something else.

## 2. Explaining the correct concept

Apostrophes do two different jobs, and you have to figure out which job is happening:

- **Job 1 — Contraction:** the apostrophe shows where letters were squeezed out. "You're" = "you are" (the "a" is missing). Same pattern: "it's" = "it is," "they're" = "they are."
- **Job 2 — Possession:** the apostrophe shows ownership, like "Maria's book." But possessive pronouns (your, its, their, his, hers) never use an apostrophe — the ownership is already built into the word.

**The test that always works:** read the sentence with "you are" in the blank.
- "___ going to love..." → "You are going to love" ✓ makes sense → use **you're** (the contraction).
- "...love ___ new phone" → "love you are new phone" ✗ nonsense — here the word shows the phone belongs to you → use **your** (the possessive).

So: **You're** going to love **your** new phone. If "you are" fits, use you're; if it shows ownership, use your.
